ow to Test the UI Application

  Quick Start (Easiest Method)

  1. Navigate to the UI directory:
  cd /Users/jjayaraj/workspaces/studios/projectsforce/bedrock/testing/ui

  2. Launch the web application:
  ./launch_webapp.sh

  This script will:
  - Install required Python packages (Flask, Flask-CORS) if needed
  - Start a CORS proxy server on port 5003
  - Start an HTTP server on port 8000
  - Automatically open the UI in your browser at http://localhost:8000/index.local.html

  Available UI Options

  Once launched, you can access different UI versions:

  | URL                                     | Description                   | Use Case                    |
  |-----------------------------------------|-------------------------------|-----------------------------|
  | http://localhost:8000/index.local.html  | Local testing with CORS proxy | Best for testing with proxy |
  | http://localhost:8000/index.aws.html    | Direct AWS API Gateway        | Best for production testing |
  | http://localhost:8000/index.html        | Main UI                       | Latest version              |
  | http://localhost:8000/pf_auth_demo.html | Authentication demo           | Testing auth flows          |
  | http://localhost:8000/test_ui.html      | Test UI                       | Simple testing interface    |

  Architecture

  Browser (localhost:8000)
      ↓
  Python HTTP Server (port 8000)
      ↓
  index.local.html → CORS Proxy (port 5003) → API Gateway (AWS)
                                                  ↓
                                              Orchestrator Lambda

  Features in the UI

  The UI provides:
  - Chat Interface - Interactive chat with the agent
  - Context Resolution - Tests implicit continuations
  - Multi-turn Conversations - Session management with history
  - Project Management - List, filter, schedule projects
  - Performance Metrics - Shows response times and routing info
  - Session Management - Start new sessions or continue existing ones

  Stopping the Application

  Press Ctrl+C in the terminal where you launched the webapp. This will:
  - Stop the CORS proxy server (port 5003)
  - Stop the HTTP server (port 8000)
  - Clean up all processes

  Logs

  If you need to troubleshoot:
  - Proxy logs: /tmp/pf_proxy.log
  - HTTP server logs: /tmp/http_server.log

  Testing Workflow

  1. Launch the UI: ./launch_webapp.sh
  2. Open in browser: Auto-opens to http://localhost:8000/index.local.html
  3. Enter credentials: Use your ProjectForce API token
  4. Start chatting: Test queries like:
    - "Show me my projects"
    - "Schedule project 7751744"
    - "What dates are available?"
    - "Show the scheduled projects"
